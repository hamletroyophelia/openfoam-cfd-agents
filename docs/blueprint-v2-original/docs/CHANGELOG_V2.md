# V2 变更摘要

日期：2026-09-05；基于 2026-09-04 方案增量更新。

| 领域 | 前版已有 | 本版落实/修正 |
| --- | --- | --- |
| 主控 | 一套确定性核心 | 保留，不叠加全流程 Agent 框架 |
| 判定 | 数值由程序计算 | 发现 NaN/Inf 比较缺口；明确有限数、validity 与负向测试 |
| 兼容 | 版本化 adapter | 按操作区分上游声明、契约测试、运行测试、科学基准证据 |
| 长任务 | job_id、持久 worker | 启动窗口核对、幂等键冲突、租约/进程身份、取消确认、检查点完整性 |
| MCP | 可替换接入层 | 记录 Tasks 迁移风险，不锁死实验 SDK |
| 建模 | 单位/参考量 | 加入物理语义契约、几何身份与重网格边界重新绑定 |
| 数据 | artifact 与脚本 | 控制/数据分离；原生数据与预览分级；不追求跨平台像素完全一致 |
| 证据 | 改动后重验 | 明确依赖图、复用边界、统计窗口变化和审批失效规则 |
| V&V | 分层可信度 | 修正解析对照与实验验证的区别；跨求解器一致不等于现实正确 |
| 安全 | 路径、权限、预算 | 增加风险分级、令牌受众、工具 annotations 信任边界与供应链准入 |
| 发布 | 分期验收 | 增加故障注入与科学负向测试，防止把已提交或错误数据标成成功 |

微信报告仍待取得正文后核对；本版不包含未经读取的报告结论。

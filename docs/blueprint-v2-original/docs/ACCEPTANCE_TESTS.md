# V2 验收与故障注入用例

**状态：待开发的验收规范，不是已执行的测试结果。** 每条用例须输出输入摘要、操作、实际状态、证据与判据版本。物理容限按 case/profile 定义，不使用跨算例统一百分比。

| ID | 注入/场景 | 预期行为 |
| --- | --- | --- |
| V2-01 | observed 为 NaN/+Inf/-Inf，分别使用六类比较符 | 不得 passed；输出非有限数据诊断；严格 JSON 可解析 |
| V2-02 | threshold 为 NaN/Inf 或指标定义/单位不匹配 | 配置拒绝或证据不可用；不能靠比较符“碰巧通过” |
| V2-03 | 同一幂等键重复提交；随后用同键更换 spec | 前者返回同一作业，后者冲突拒绝 |
| V2-04 | 网关在返回 job_id 前断线 | 重试可查到原提交，不额外启动求解 |
| V2-05 | 求解启动后、worker 写回运行 ID 前崩溃 | 通过持久 launch intent 与真实进程核对；不确定则阻止重启 |
| V2-06 | worker 租约到期但旧 MPI 仍活跃 | 不创建第二个写入者；人工/程序核对后接管 |
| V2-07 | 取消接口返回 ACK，MPI 尚未结束 | 显示 cancel_requested，确认结束后才 cancelled |
| V2-08 | 最近时间目录缺少一个字段或部分 rank 未写完 | 拒绝作为检查点；选择通过检查的旧时间或阻止续算 |
| V2-09 | 持有其他项目的 job_id/artifact_id | 状态、取消与文件读取均拒绝越权 |
| V2-10 | 物性、边界条件、网格或时间策略改变 | 创建新修订，相关验证和审批不再适用于新修订 |
| V2-11 | 只改变相机；另一组改变统计窗口 | 前者保留数值证据；后者重算相关统计/验证结论 |
| V2-12 | 上游返回 completed，但只是作业提交或含业务错误 | 不映射成求解成功或科学通过 |
| V2-13 | 工具 schema/求解器发行分支改变 | 兼容性证据失效，拒绝静默套用模板 |
| V2-14 | 导入几何单位变化或重网格后面编号变化 | 单位与边界绑定检查必须发现差异 |
| V2-15 | 并行失败后上游自动串行回退 | 不计入原 MPI 配置排名；记录失败/回退事实 |
| V2-16 | 固定步数试跑、但统计窗口过短 | 可以输出性能，不能输出网格精度或统计收敛通过 |
| V2-17 | 非单调网格序列、采样噪声主导或不可比加密 | 返回适用性诊断和 inconclusive，不强制 GCI 通过 |
| V2-18 | 不规则采样、重启重复时间或强相关块 | 时间加权/去重/相关性处理受测；不能直接常规 FFT 或虚增样本 |
| V2-19 | 对照解析解或另一求解器，但没有实验数据 | 记录数值验证/交叉检查；物理验证未建立 |
| V2-20 | 体场很大、Agent 请求整场；预览发生降采样 | 受控摘要与 artifact 访问；明确预览损失，不把预览当原始证据 |
| V2-21 | 恶意 skill 声称只读却要执行动态代码 | annotations 不提升权限；隔离或拒绝并记录 |
| V2-22 | 无效受众 token 或任意远端资源 URL | 认证/网络策略拒绝，不透传凭据或访问未授权地址 |
| V2-23 | CPU/内存/磁盘不足，或预算已耗尽 | 不启动/按授权安全停；保留部分结果，不生成合格配置 |
| V2-24 | UI 或 MCP 不可用，但 CLI 和 worker 正常 | 核心能继续管理作业、生成数据与报告 |

首批真实测试可用小型层流通道完成运行、守恒和解析对照；后续非定常与 VOF 用例的参考来源、单位、工况和容限须单独定义。合成 fixture、源码审查、契约测试和真实求解证据分别标注。

对测试集的“无错误放行”不等于对所有未来问题的形式化安全保证。发现新反例后加入回归，并重新评估受影响的版本。
